# 🌊 Flood Disaster Intelligence and Response Platform

A national-level hackathon project for real-time flood disaster intelligence, monitoring, and coordinated emergency response.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + Vite |
| Backend | Python + FastAPI |
| Database | Supabase + PostgreSQL/PostGIS |
| Geospatial | Leaflet + OpenStreetMap + GeoJSON |
| AI | YOLOv8 + OpenCV |

## Features (Planned)

- Real weather and rainfall data integration
- Flood risk intelligence and zone mapping
- Citizen incident reports
- Emergency prioritization engine
- Volunteer / resource dispatch
- Drone / video AI analysis
- Offline-first citizen emergency interface
- Disaster command dashboard

## Project Structure

```
/
├── frontend/       # React + Vite application
├── backend/        # FastAPI server
├── ai/             # YOLOv8 / OpenCV AI modules
├── database/       # SQL migrations and seeds
├── data/           # Raw and processed geospatial/weather data
├── docs/           # Architecture and API documentation
└── tests/          # Automated tests
```
